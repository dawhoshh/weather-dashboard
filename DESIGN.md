# Обґрунтування дизайн-рішень (Практична робота №5)

## Чітка вимога
Фон секції поточної погоди задано кольором `#1e40af`, що чітко потрапляє у вказаний технічним завданням діапазон від `#123069` до `#2E5A8C`. Для дотримання стандарту доступності (WCAG) використано білий колір тексту (`#ffffff`), який забезпечує високий коефіцієнт контрастності (понад 4.5:1) на темно-синьому тлі.

## Нечітка вимога
**Завдання:** «Щоб користувач одразу відчував, тепло чи холодно надворі».
**Рішення:** Впроваджено кольорову індикацію для значень температури:
1. Для прохолодної погоди (нижче +18°C) використовується холодний синій відтінок (`#0369a1`), який асоціюється з прохолодою.
2. Для комфортної теплої погоди (+18°C...+25°C) застосовано м'який помаранчевий колір (`#a16207`), що символізує сонце та тепло.
3. Для спекотної погоди передбачено насичений червоний колір (`#b91c1c`).
   Такий підхід дозволяє зчитувати інформацію не лише через числа, а й на інтуїтивному візуальному рівні.

## Деталі дизайну
Згідно з вимогами, розмір шрифту температури в картках збільшено до 32px (жирне накреслення), а текстовий опис прогнозу зменшено до 14px для створення чіткої візуальної ієрархії. Іконку погоди збільшено до 64x64px та відцентровано, що робить її головним акцентним елементом кожної картки.
